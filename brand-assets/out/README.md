# Oriana Logo & Brand Assets

The mark is the "O" of Oriana, set in the site's own serif typeface
(Cormorant Garamond), with a small diamond jewel in its counter and the
flanking-line motif already used for dividers across your website. Same
gold/rose/pink gradient as the site, so everything matches what's already
live.

## logo/

- **logo-horizontal-transparent.png** — icon + "Oriana" + tagline, side by
  side. The main one for website headers, email signatures, documents.
- **logo-stacked-transparent.png** — icon above the wordmark, for square
  spaces (app icons, printed cards, anywhere a wide logo doesn't fit).
- **logo-stacked-no-tagline-transparent.png** — same, without the
  "Event Decor · Lahore" tagline, for smaller placements.
- **logo-horizontal-on-cream.png / -on-dark.png** — same lockup pre-composed
  on a solid cream or dark background, for contexts that can't handle
  transparent PNGs (some print/ad platforms).
- **logo-horizontal-white-transparent.png** — white version for placing over
  photos or dark colors.
- **icon-mark-gold-*.png** (32 to 1024px) — the mark alone, no text. Use for
  app icons, watermarks, anywhere you need just the symbol.
- **icon-mark-cream-512 / -white-512 / -ink-512.png** — the mark alone in
  other colors for different backgrounds.

## favicon/

- **favicon.ico** — drop this in your website's root folder as `favicon.ico`
  and it's the icon shown in browser tabs. Uses a simplified version of the
  mark since the full detail doesn't survive at 16-32px.

## social/

Ready to upload as-is:

- **social-profile-picture-1080x1080.png** — profile photo for Instagram,
  Facebook, LinkedIn, WhatsApp Business, etc. Every platform crops this to a
  circle, so the mark is centered with margin for that.
- **social-facebook-cover-820x312.png** — Facebook Page cover photo.
- **social-twitter-x-header-1500x500.png** — X/Twitter header image.
- **social-linkedin-cover-1584x396.png** — LinkedIn Page cover photo.
- **social-instagram-post-1080x1080.png** — a plain branded square (no
  tagline) you can post directly or use as a template base.

## Notes

- All PNGs are transparent unless the filename says otherwise — they'll
  drop cleanly onto any background.
- The gold used is `#E8B923`, matching the website exactly.
- Source files are hand-built (not AI-generated) as clean vector-style
  shapes, so they hold up at any size without getting blurry or artifacted.
